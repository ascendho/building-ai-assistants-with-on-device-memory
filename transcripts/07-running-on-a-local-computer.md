# Running on a Local Computer

Source: https://learn.deeplearning.ai/courses/building-ai-assistants-with-on-device-memory/lesson/53fyuz/running-on-a-local-computer

In this lesson, we will run the same code that powered our AI assistant device on a local computer. Let's go. Starting from the repo that is provided in course materials, the first step is to clone it. To clone the repo, you can use HTTPS, the GitHub Copilot app, or GitHub Desktop. Then, once the repo is cloned, use your IDE of choice to open it and open the getting-started guide. To get started, you simply need an operating system, either Windows, macOS, or Linux, Python 3.12 or newer, and uv. If you don't already have uv, you can just install it from your CLI by, for example, typing brew install uv. Then, a webcam and a microphone, and enough disk space for a gig and a half Then to install the project, you can just copy these commands and paste it into your CLI. uv sync is going to download all the packages, and this command is going to create the .env file. In the .env file you have all the configuration for this project. First we have the RECOGNIZE_THRESHOLD that we've talked about in a previous lesson, detection configuration depending on your camera and also depending on the distance of the objects that you want to recognize. And then lastly some camera and microphone settings depending on the hardware that you have. Those settings will work on most hardware configurations, so you probably do not need to touch those settings. Then lastly you can just scroll down to this command. copy it in your CLI and paste it.
