In this course, you'll build an on-device memory system that can remember notes, photos, voice recordings, and retrieve them later by meaning. You'll also see how to teach it to recognize new objects from photos. All of this will happen without sending these memories to remote servers. Memory is important for delivering customized experiences to users, and on-device memory allows you to do this without depending on network connectivity and with greater user privacy. You'll first learn how to build an on-device memory, how an experience is captured, encoded as a vector, stored with useful metadata, recalled later and eventually forgotten. Then, you'll see how these pieces come together in a physical assistant, specifically, how to use object detection CLIP embeddings and local vector memory to let the assistant remember what it has seen and learn new objects without retraining a model. From there, you'll build the memory system yourself using our open source Qdrant edge vector search engine. You'll store and retrieve text memories, search them by meaning, filter them using metadata, explicitly forget them, and extend the same approach to searching images with natural language. Next, you'll bring text notes, voice recordings, and photos together into an offline assistant that can answer questions about experiences from your day. And finally, you'll teach the device to recognize new objects from examples you add to its memory. You'll see the difference between retrieving the nearest visual memory and actually recognizing an object. and calibrate a similarity threshold that determines when a retrieved memory is close enough to count as a match.
